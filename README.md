# Portfólio do Professor Zezinho — Filosofia

Site responsivo para o componente curricular de Filosofia do Centro Educa Mais Dom Ungarelli.

## Como abrir no VS Code
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o VS Code e selecione **Arquivo > Abrir Pasta**.
3. Escolha a pasta `portfolio_professor_zezinho_filosofia`.
4. Abra `index.html`.
5. Se tiver a extensão **Live Server**, clique com o botão direito no `index.html` e escolha **Open with Live Server**. Também é possível abrir o arquivo diretamente no navegador.

## Estrutura
- `index.html` — conteúdo e seções do portfólio.
- `style.css` — cores, layout e adaptação para celulares.
- `script.js` — menu responsivo e configuração do contato.
- `assets/professor-zezinho.jpeg` — retrato fornecido.
- `assets/logo-dom-ungarelli.jpeg` — logo fornecido.

## Personalizações
- **Nome:** o portfólio usa “Professor Zezinho”, conforme solicitado.
- **Contato:** abra `script.js` e informe o e-mail profissional em `emailProfessor`.
- **Projetos:** no `index.html`, edite os cartões da seção “Experiências e Registros” e acrescente nomes, datas, textos e links das atividades reais.
- **Fotos:** substitua ou acrescente imagens na pasta `assets` e atualize os caminhos no HTML.
- **Textos:** revise as descrições para refletir o planejamento e as atividades efetivamente realizadas com as turmas.

O site utiliza fontes do Google Fonts quando há conexão com a internet; sem conexão, usa fontes alternativas instaladas no sistema.
